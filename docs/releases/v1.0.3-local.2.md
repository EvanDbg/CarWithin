# CarWithin Local v1.0.3-local.2

应用版本：1.0.3 / build 17。此版本继续作为实验性预发布。

## 修复

- 修正仅本机和 LocalDevVPN 模式的控制监听器重复指定端口问题：本地绑定地址与端口只通过 `requiredLocalEndpoint` 设置，避免在创建 `NWListener` 时再次传入固定端口。
- 控制监听器和 LocalDevVPN 回送探测使用同一个创建入口，保持监听地址限制，不回退到公开监听。
- 增加固定端口的实际连接和地址隔离回归检查，以及端口占用后的自动端口路径检查。
- 为启动请求增加来源与尝试编号，为监听器增加模式、绑定地址、请求端口和实际端口诊断。
- 停止、失败和模式切换时取消旧的延迟重启，防止过期的重配置任务重新启动会话。

## 安装与复测

下载 `CarWithin-Local-unsigned.ipa`，沿用现有签名方式安装。安装后先检查“设置 → 配件身份”的状态。公共安装包不包含配件身份或 Apple 签名材料。

先复测原先出现错误的 LocalDevVPN 模式，观察是否出现实际 RTSP 监听地址、配件认证结果和持续更新的画面；再分别验证“仅本机（无需 VPN）”在 Wi-Fi 未连接和 Wi-Fi 完全关闭时的表现。发生失败时保存完整启动日志、App build 和 iOS 版本。

## 验证范围

发布前运行核心测试、本机网络实测及完整 iOS Release 无签名构建，具体结果以对应 GitHub Actions 记录为准。这些检查不等于在 iPhone 上完成了 CarPlay 配件认证、VPN 回送或持续画面验证；真机结果仍待反馈。
